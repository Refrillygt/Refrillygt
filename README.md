## About Me

I'm a software engineering student and full stack developer passionate about building meaningful products. I care about clean architecture, readable code, and experiences that feel effortless to use.

- Currently studying and building at the intersection of web development and design
- Comfortable across the full stack — from database schema to UI components
- Interested in systems thinking, developer tooling, and product engineering
- I use Linux as my daily driver and enjoy tinkering close to the metal
- Believer in shipping fast, iterating often, and writing code that others can understand
